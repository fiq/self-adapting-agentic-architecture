# Agentic Template

Before substantive work, run `.agentic-template/bin/project startup` first, or
read `../AGENTS.md` from disk yourself. Confirm that `AGENTS.md` was read from
disk, then review the startup sequence and options before choosing the next
command.

Use `.agents/skills/CATALOG.toon` to find relevant canonical repository skills.
Load only the needed `.agents/skills/.../SKILL.md` files for the task; do not
copy the whole skill tree into context.

For non-trivial work, read `HANDOFF.toon`, `PROJECT_PROFILE.toon` and
`.agents/knowledge/index.md` before planning or implementation.
