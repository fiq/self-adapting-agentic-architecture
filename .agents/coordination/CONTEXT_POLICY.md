# Context Policy

1. Search before reading whole directories.
2. Load only relevant skills.
3. Start from `AGENTS.md`, `HANDOFF.toon`, `PROJECT_PROFILE.toon`, active spec
   and relevant paths.
4. Use `context-packet` for delegation, review or context-pressure handoff.
5. Give subagents bounded context: objective, acceptance, non-goals, risks and
   source refs before snippets.
6. Share concise factual summaries with file refs; include exact snippets
   only when exact wording or code shape matters.
7. Preserve disagreement on interpretation, not duplicate discovery.
8. Capture unknowns structurally instead of re-discussing them.
9. Do not resend unchanged context.
10. Do not encode semantic context into opaque transport blobs.
